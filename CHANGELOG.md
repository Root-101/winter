* 0.1.0:
    * **DATE** :date: : Unreleased.
    * **Breaking** :warning: : Code moved to `lib/src/`, import only `package:winter/winter.dart`. `winter.dart` no longer re-exports `shelf_multipart`, `string_scanner` nor `http_parser` internals (`shelf` is still exported).
    * **Breaking** :warning: : `HttpHeaders` => `HttpHeader` and `HttpStatus` => `StatusCode`, so they no longer shadow the `dart:io` classes.
    * **Breaking** :warning: : `ResponseEntity.ok` is a named constructor (`ResponseEntity.ok<int>(...)` => `ResponseEntity<int>.ok(...)`).
    * **Breaking** :warning: : A 500 never exposes the error, it's logged instead. `SerializationException` is a 500 (it was a 400).
    * **Breaking** :warning: : `LogsFilter` never logs bodies nor query params. `logResponse` receives the request, the response & the duration; `logErrorResponse` was removed.
    * **Breaking** :warning: : `AuthFilter` returns 401 (not 403) when nobody is authenticated.
    * **Breaking** :warning: : `ServerConfig.maxBodySize` (default 10 MB) rejects bigger bodies with a 413.
    * **Security** :lock: : Route filters (including `AuthFilter`) are applied inside a `MultiRouter`.
    * **Security** :lock: : CORS with `'*'` & credentials echoes the origin. Errors thrown by filters or handlers keep the CORS headers.
    * **Security** :lock: : `RequestEntity.clientIp()` (ignores `X-Forwarded-For` unless `trustedProxies` is set), used by default in `RateLimiterFilter`. `buildValidator(name, sensitive: true)` hides the value in the violations.
    * **Router** :twisted_rightwards_arrows: : Fix: nested routes with the same relative path in different parents were dropped. Static routes have priority, path params are url-decoded, trailing slashes are ignored, a lone `.` is literal, HEAD uses the GET route and 405 includes `Allow`. `MultiRouter` returns 404/405 instead of 500. `addRoute` applies the `basePath` & the validations.
    * **Router** :twisted_rightwards_arrows: : ~25x faster routing (route regex compiled once, see `benchmark/`).
    * **Server** :rocket: : Graceful shutdown on SIGINT/SIGTERM (`ServerConfig.handleSignals`, `shutdownTimeout`, `onShutdown`), `Winter.shutdown()` & `Winter.close(timeout:)`.
    * **Testing** :test_tube: : `Winter.buildHandler` & `WinterTestClient`: test the whole pipeline in memory, without ports.
    * **i18n** :globe_with_meridians: : Validation messages in the language of the request (`Accept-Language`, `request.locale`, `LocaleConfig` in the `BuildContext`), typed translations generated by `slang` from YAML. `ConstrainViolation.message` is in the language of the request. The default validation texts no longer include the field name.
    * **Request scope** :link: : Each request runs in its own `Zone`: `requestAuthentication`, `requestSecurityContext` and `requestLocale` work from any code without receiving the request (`RequestScope`). The texts are resolved with `requestLocale` when they are created: `LocalizedText`, `addLocalizedRule` and `ConstrainViolation.localizedMessage` were removed, and the custom `message` of the built-in validators is a `String`. Reading the language (`requestLocale`, `request.locale`) adds `Vary: Accept-Language` to the response automatically.
    * **Logging** :memo: : Every log goes through `WinterLogger` (`logger`, default `ConsoleLogger` with levels), replaceable in the `BuildContext`.
    * **Request** :inbox_tray: : `body<T>()` can be called many times. `change()` is implemented for `RequestEntity` & `ResponseEntity` (shelf middlewares).
    * **Response** :outbox_tray: : Fix: `CorsFilter` & `RateLimiterFilter` lost a body set with `change()` (or sent its bytes as JSON), and serialized the body again. `copyWith()` without a new body keeps the resolved body, a response without body gets no `Content-Type`, and CORS merges its `Vary: Origin` with the one of the response.
    * **Request** :inbox_tray: : `queryParamsAll` with every value of a repeated query param (`?tag=a&tag=b`).
    * **Server** :rocket: : Fix: `Winter.start` uses any router registered in DI as `AbstractWinterRouter` (ex: a `MultiRouter`), not only a `WinterRouter`.
    * **Object Mapper** :card_file_box: : `Map` deserialization, `Deserializer<T>.json(fromJson)`, recursive serialization of `toJson()` results, enums, `Set` & non String map keys.
    * **Breaking** :warning: : Object mapper review (`DECISIONS.md` §2). `Serializable` was removed: `toJson()` is called dynamically, so `json_serializable`/`freezed` models work as they are. `deserialize` only takes JSON values; use `decode` for JSON text (and `encode` for `jsonEncode(serialize(...))`). Primitives are strict (`"12"` is not an `int`, `"true"` not a `bool`; `12.0` is an `int`). `DateTime` is serialized in UTC. `deserializeList`/`deserializeMap`, `ListTypeExtension` and the default `Serializer<num>`/`Serializer<Object>` were removed. A missing serializer or deserializer throws `MissingSerializerError`/`MissingDeserializerError`.
    * **Object Mapper** :card_file_box: : Generic types are found by `Type`, not by name (fixes two classes with the same name and `--obfuscate`): `T?`, `List<T>`, `Set<T>`, `Map<String, T>` are derived from `T`, deeper types with `deserializerOf<T>().list()`/`set()`/`map()`/`nullable()`. A serializer applies to subtypes (`freezed`, sealed classes). Errors say where the value is (`$.items[1]: expected a string, got an integer`) and never expose Dart internals, type names nor file paths. `encode` works in a single pass with a cache per type: ~3x faster (`benchmark/object_mapper_benchmark.dart`). Options `includeNulls`, `fieldNaming`, `durationFormat` and `prettyPrint`.
    * **Breaking** :warning: : The JSON of the responses is indented by default (`ObjectMapper.prettyPrint: true`); use `ObjectMapper(prettyPrint: false)` for compact JSON.
    * **Breaking** :warning: : `RequestEntity.body<T>(om: ...)` => `body<T>(objectMapper: ...)`, like `ResponseEntity` and `BuildContext`.
    * **Breaking** :warning: : Validation review (`DECISIONS.md` §3). `cvc.buildValidator(name)....validate(value)` => `cvc.field(name, value)....`: the rules run as they are chained (a forgotten `.validate(value)` validated nothing) and the validators depend on the type of the value (`.min()` on a String doesn't compile). `ConstrainViolation` => `ConstraintViolation`; `ConstraintValidator` and `List<Validatable>.validate()` were removed (use `validEach()`). `Validatable` is an interface without a default `validate()`. The 422 never includes the value (it was a 500 when the value had no `toJson()`). `body<T>()` validates a `Validatable` body by default (`validate: false` to skip it).
    * **Breaking** :warning: : Error handling review (`DECISIONS.md` §4, `doc/error-handling.md`). Every error is a Problem Details (RFC 9457, `application/problem+json`); the 422 has a `violations` member. `ApiException(status, detail:, type:, title:, extensions:, headers:)` replaces `ApiException(statusCode:, body:)` (and `body:` of every shortcut); `PaymentRequiredException` was removed. `ExceptionHandler.call` receives `Object` (Exceptions and Errors). The router throws `NotFoundException`/`MethodNotAllowedException`, `AuthFilter` throws `UnauthorizedException`/`ForbiddenException` (`build401`/`build403` were removed) and `RateLimiterFilter` throws `TooManyRequestsException`. The `ExcHandler` typedef was removed.
    * **Breaking** :warning: : Configuration review (`DECISIONS.md` §6, `doc/configuration.md`). `env.find(key, required: true)` => `env.require<T>(key)` (returns a `T`, not a `T?`). `ServerConfig` is `const`, with `host: String` instead of `ip: InternetAddress`, and `Winter.start(shared:)` => `ServerConfig(shared:)`. A `String` read by `Env` is no longer trimmed. `Env.put` returns the value given.
    * **Logging** :memo: : Logging review (`DECISIONS.md` §7, `doc/logging.md`). `JsonLogger` (one JSON per line for production), every level takes `error`, `stackTrace` and `fields`, `isEnabled(level)`. Every request has an id (`X-Request-Id` if valid, or a new UUID) in the `RequestScope` (`requestId`), the response, every log and a 500. `ConsoleLogger` writes the time in UTC. Fix: the debug log of a failed deserialization included the value sent (personal data). **Breaking**: a custom `WinterLogger.log` takes `fields`.
    * **Configuration** :gear: : `Env.load()` reads `.env` and `.env.<profile>` (`WINTER_PROFILE`) under the variables of the process. `requireAll([...])` names every missing variable, `Duration` (`30s`), `Uri`, enums (`findEnum`/`requireEnum`) and nullable types are supported, and `List<bool>` accepts any case. Fix: the error of a wrong type showed the value (a secret could end in the logs). `ServerConfig.fromEnv(env)` reads `PORT` and `HOST`, and `Winter.start` validates the `ServerConfig` before opening the port.
    * **Dependency Injection** :syringe: : Dependency injection review (`DECISIONS.md` §5, `doc/dependency-injection.md`). `putLazy` (created by the first `find`, with a clear error on cycles), `putFactory` and `putScoped` (one instance per request), `onDispose` called in reverse order by `Winter.shutdown()` (or `di.disposeAll()`), `isRegistered<T>()` and `null` values. Fix: a dependency registered from a nullable variable (`<Service?>`) wasn't found as `<Service>`. `RequestScope.onComplete` runs code at the end of a request. A lazy singleton that depends on a scoped one (a captive dependency, it kept the disposed instance of the first request) and a scoped `find` after its request ended are a `StateError`; `RequestScope.isCompleted`. **Breaking**: `delete` returns `T?` (`null` if the instance was never created) and `notFound` is private.
    * **Errors** :rotating_light: : Fix: an `Error` (a `StateError`, a `TypeError`...) gave a 500 without the CORS headers and without going through the filters nor the `ExceptionHandler`. `SimpleExceptionHandler..on<T>((request, e) => ...)` answers an exception of the app (the most specific type wins). New `MethodNotAllowedException`, `TooManyRequestsException` and `ServiceUnavailableException`, and a public `ProblemDetails`. A broken `ExceptionHandler` still gives a generic 500.
    * **Validation** :white_check_mark: : Chaining keeps the type of the field (`field('items', items).notEmpty().validEach()`), `fieldName` follows the `fieldNaming` of the mapper (`ObjectMapper.jsonFieldName`), `url()` rejects whitespace, `email()` checks the RFC 5321 lengths, the `params` of `oneOf`/`isEnum` are only JSON values, and `violationsOf(fieldName)` for tests.
    * **Validation** :white_check_mark: : Each violation has a `code` and `params`. `valid()`/`validEach()` for nested objects and lists. New validators: `url`, `uuid`, `positive`, `negative`, `positiveOrZero`, `negativeOrZero`, `past`, `future`, `pastOrPresent`, `futureOrPresent` (with a `clock`), `notEmpty`, `oneOf`; `size` and `notEmpty` accept a `Map`. Fix: `pattern()` with a `RegExp` never matched, and `ConstraintViolation.==` compared values as strings.
    * **Object Mapper** :card_file_box: : `Deserializer.enumByName(Status.values)` reads enums by name, and `Deserializer<T>.string`/`integer`/`number`/`boolean` check the JSON type before converting it (`$.url: expected a string, got an integer`).
    * **Request** :inbox_tray: : `body<T>()` answers 415 (`UnsupportedMediaTypeException`) for a `Content-Type` that is not JSON (`text/plain` and none are read as JSON), `body<String>()` decodes a JSON string, and an empty body is `null` for a nullable `T`.
    * **Dependency Injection** :syringe: : Every instance has its own dependencies, `Winter.close()` restores the ones registered by `Winter.start()`.
    * **Rate Limiter** :stopwatch: : Inactive ids are purged automatically, `X-RateLimit-Reset` is the time until a new slot.
    * **General** :hammer_and_wrench: : Email validator accepts `+` & long TLDs, `Env.find<int>` is strict, `MediaType` values are `const`, `ApiException.toString()`, analyzer with `strict-casts` & `strict-inference`, examples moved to `example/` (secure auth example: hashed passwords, expiring JWT).
